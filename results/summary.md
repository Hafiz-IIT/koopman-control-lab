# Koopman scalar prediction benchmark — v0.1

**Status:** completed synthetic pilot; not a control or physical-robotics result.

- 5 declared synthetic scalar maps
- 10 fixed seeds (0–9)
- 600 training transitions, 300 in-distribution test transitions, 300 out-of-range test transitions per seed/system
- 100 independent 20-step rollouts per seed/system
- Baselines: persistence and fitted affine linear model
- EDMD ablations: polynomial dictionary degrees 2 and 3
- Ridge coefficient fixed at 1e-8 before test evaluation
- Values below are mean ± sample standard deviation across 10 seeds

## Preliminary interpretation

1. Degree-3 lifting substantially reduces one-step error on the smooth nonlinear maps represented by low-order polynomial structure.
2. Degree-2 adds little over the affine baseline on the odd cubic, sinusoidal, and tanh systems; it helps on the quadratic-affine system.
3. Better one-step fit does not guarantee better long-horizon rollout. On the piecewise regime-shift system, degree 3 has lower one-step RMSE but worse 20-step RMSE than persistence and the affine baseline.
4. Out-of-range performance is system-dependent. The degree-3 tanh model has lower in-distribution error but worse OOD RMSE than the affine baseline.

The near-zero one-step errors on cubic and quadratic-affine maps are expected because those noiseless synthetic functions are exactly representable by the selected polynomial dictionary. They are not evidence of generalization to unknown physical systems.

## Reproducibility

- Per-seed CSV: `koopman_scalar_per_seed.csv` (generated by `python experiment.py`; also uploaded as a GitHub Actions artifact).
- Aggregate CSV with 95% t-intervals: `koopman_scalar_summary.csv`.
- Configuration and limitations: `manifest.json`.

The runner uses only the Python standard library and the repository's `koopman_lift.py`. No external dataset or physical sensor data are used.
