# Results

This directory contains the human-readable summary and configuration for the scalar EDMD prediction benchmark.

- `manifest.json`: fixed experiment configuration and scope limitations.
- `summary.md`: committed human-readable results and preliminary interpretation.
- `koopman_scalar_per_seed.csv`: generated per-seed output.
- `koopman_scalar_summary.csv`: generated aggregate means, standard deviations, and 95% t-intervals.

The two CSV files are generated by `python experiment.py` and uploaded by the GitHub Actions workflow as the `koopman-scalar-benchmark` artifact. Download that artifact from the latest successful CI run to inspect the complete machine-readable outputs.

Regenerate locally with:

```bash
python experiment.py
```

All data are synthetic. These results are a prediction pilot, not evidence of Koopman invariance, control utility, or physical-system validity.
